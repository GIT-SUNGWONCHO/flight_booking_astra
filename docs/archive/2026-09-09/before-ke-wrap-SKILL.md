# 세션 마감 (3분 안에 끝낸다. 길어지면 안 하게 된다)

## 1. 오늘 새로 잰 것이 있나 → FACTS.md 에 한 줄

"실측/확인/재보니" 라고 말한 것 전부가 후보다. 판단 기준 하나:
**이 저장소를 clone 한 다른 사람에게도 참인가?** 참이면 FACTS.md,
이 PC·이 계정에만 참이면 내 메모리 디렉터리(아래 4번).

형식: `- 사실 한 줄. (MM-DD, 어떻게 쟀는지 한 마디)`
틀린 것이 밝혀졌으면 그 줄을 고치고 `(구: …)` 를 남긴다. 지우지 않는다.
막다른 길이면 "막다른 길" 절로. **왜 안 되는지까지 적어야 다시 안 판다.**

상한 90줄. 넘으면 코드가 더 이상 의존하지 않는 사실부터 지운다.

## 2. NOW.md 를 통째로 다시 쓴다

  갱신 날짜 / 이번 주 목표 / 내일 09:00 에 무엇을 왜 재나 /
  지난 09:00 결과 1~2줄 / 지금 미검증인 것

이력은 남기지 않는다 — git 이 갖고 있다. 25줄을 넘기지 않는다.

## 3. 열린 것은 BACKLOG.md 로

이번에 발견했지만 안 고친 결함, 새로 생긴 의문. 번호를 준다.
"나중에 본다" 는 대화에 남기지 말고 여기에 남긴다.

## 4. 이 PC 에만 참인 것은 메모리로

사내망/사외망, 크롬 포트와 프로필과 계정, 사용자의 목표 날짜.
저장소는 공유되고 푸시되므로 여기 넣지 않는다. 메모리 파일은 5개를 넘기지 않는다.

## 5. 09:00 직후라면 추가로

`dev-shots/` 의 리포트(`autorun_report.json`, `watch_seats.json`)를 **직접 읽고**
숫자를 인용한다. "돌았다" 가 아니라 "7단계 도달 10.0초 / 좌석 1→0 은 +6.2초" 처럼.
그 두 숫자의 차이가 곧 "몇 초 부족한가" 다 — 이 프로젝트의 유일한 점수판이다.
FACTS.md 의 경쟁 절과 NOW.md 의 지난 결과에 반영한다.

## 마지막

사용자에게는 **무엇을 어느 파일에 적었는지**를 한 줄로 보고한다.
파일에 안 적힌 것은 내일 없는 것이다.
