# 검증 근거와 해석 한계


역할: 실제 관측·코드 대조·시험 결과를 보존한다. 운영 명세는 [README](../../../README.md), 현재 상태·후속 과제는 [NOW](../../../NOW.md)에 둔다. 정리 기준일은 2026-09-11이며, 각 관측의 실제 날짜는 항목별 근거를 따른다.

## 1. 근거 읽는 법

- **실사이트 관측**은 해당 노선·시각·환경에서 확인한 사실이다. 다른 노선이나 실제09시 성공으로 일반화하지 않는다.
- **코드 대조**는 구현 설명이다. 실사이트 성공·업무상 주문 수락을 입증하지 않는다.
- **해석 한계**는 확인하지 못한 범위다. 보고서의 `ok`·HTTP 200·종료 코드 하나로 빈 부분을 채우지 않는다.
- 아래 `dev-shots/` 근거는 로컬 파일이다. 새 복제본에 없으면 증거를 전달받거나 해당 시험을 다시 수행한다.
