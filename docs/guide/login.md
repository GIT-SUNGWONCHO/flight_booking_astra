# 로그인

프로그램은 계정·쓰임마다 **전용 Chrome 창**을 하나씩 쓴다([자리 표](config.md#16-브라우저-자리)). 로그인은 창마다 따로
저장되므로, 처음에 창마다 한 번씩 로그인해 둔다.

```powershell
.\astra.cmd login
```

이 명령이 쓰는 창을 차례로 띄우고, 로그인하고, 달력 화면까지 열리는지 확인한다.
계정 하나만 다시 하려면 `.\astra.cmd login --account me`.

## 1. 스카이패스 아이디로 로그인하는 계정 (`"login": "skypass"`)

사람이 할 일이 없다. 프로그램이 `.env` 의 아이디·비밀번호로 스스로 로그인한다([.env 채우기](config.md#2-env--아이디와-비밀번호)).
실전 날 아침에도 스스로 한다.

```
── 자리 9232 · 계정 wife · 1순위 ──
[ 확인 ] 로그인됐고 달력까지 열린다
```

안 될 때:

| 화면에 나온 말 | 원인과 처리 |
|---|---|
| `.env 의 KE_SKYPASS_ID·KE_SKYPASS_PW 가 비어 있다` | 메모장으로 `.env` 를 채운다. 둘째 계정이면 `_2` 가 붙은 줄 |
| `로그인 필요: 스카이패스 로그인 실패` | 아이디·비밀번호가 틀렸거나 탭이 틀렸다. `.env` 의 `KE_LOGIN_TAB` 에 `아이디` 또는 `스카이패스` 를 적어 본다. 대한항공 누리집에서 직접 로그인되는지도 본다 |
| 창에 문자 인증·보안 문자가 떠 있다 | 그 창에서 사람이 한 번 통과시킨다. 집 PC 에서는 뜬 적이 없다(2026-09). 새 PC·새 지역에서는 뜰 수 있다 |

## 2. 네이버 연동 계정 (`"login": "naver"`)

**처음 한 번은 사람이 직접 로그인한다.** 프로그램은 네이버 비밀번호를 다루지 않는다.

`astra login` 이 Chrome 창을 **보이게** 띄우고 이렇게 말한다:

```
── 자리 9242 · 계정 me · 1순위 ──
  이 창은 사람이 직접 로그인해야 한다. 방금 뜬 Chrome 창에서:
    1. 대한항공 화면 오른쪽 위 [로그인]을 누른다
    2. [네이버 로그인]을 눌러 아이디·비밀번호를 넣는다
    3. 네이버 로그인 화면의 "로그인 상태 유지"를 반드시 켠다
  로그인되면 자동으로 다음으로 넘어간다(최대 10분 기다린다)...
```

그대로 한다. 로그인되면 프로그램이 알아채고 다음 창으로 넘어간다.

- **"로그인 상태 유지"가 핵심이다.** 켜 두면 네이버가 그 창을 기억해서, 실전 날 아침에 프로그램이 [네이버 로그인] 버튼만
  눌러도 비밀번호 없이 들어간다. 꺼 두면 그날 아침 비밀번호를 묻는 화면에서 멈춘다 — 그 자리에 사람이 없으면 그 실행은 끝이다.
- 네이버 연동 계정 하나가 창을 최대 세 개 쓴다(1순위·대체·계측). **창마다 따로 로그인한다.**
- 네이버 2단계 인증을 쓰면 창마다 휴대폰 확인이 한 번씩 온다.
- 기억은 **약 한 달** 간다(2026-09-19~24 에 로그인한 창이 10-19~24 에 만료될 예정이었다).
  실전이 한 달 넘게 남았으면 실전 며칠 전에 `astra login` 을 다시 한다.

카카오·구글 등 다른 연동 로그인은 해 보지 않았다. 대한항공 아이디·비밀번호를 만들어 `"skypass"` 로 쓰는 편이 무인 실행에 맞다.

## 3. 로그인이 살아 있는지 보기

```powershell
.\astra.cmd check --online
```

모든 창을 띄워 실제로 로그인하고 달력까지 가 본다(3~4분, 주문·좌석 선택은 하지 않는다).

```
[ 확인 ] 자리 9232(wife 1순위): 로그인돼 있고 달력이 열린다
           캡처 날짜로 쓸 수 있는 날: 2027-09-15 (일반석 있음). 실전 아침에 다시 고른다
[ 확인 ] 자리 9242(me 1순위): 로그인돼 있고 달력이 열린다
```

**실전 전날 저녁에 반드시 한 번 돌린다.** `[ 문제 ] … 로그인 필요 → astra login` 이 나오면 그 계정을 다시 로그인한다.

## 4. 알아 둘 것

- 대한항공 로그인은 **약 57분** 뒤에 끊긴다. 그래서 프로그램은 실전 40분 전(08:20)에 창을 새로 띄워 다시 로그인한다.
  전날 밤에 로그인해 둔 것은 "네이버가 이 창을 기억하게 하는 것"이지 "그 로그인을 아침까지 유지하는 것"이 아니다.
- 같은 계정으로 창 두 개에 동시에 로그인해도 서로 끊기지 않는다(2026-09-22 에 8번 번갈아 조회해 확인).
- 이 창들을 평소 인터넷용으로 쓰지 않는다. 화면 크기를 바꾸거나 다른 사이트로 가면 준비가 어긋난다.
- 로그인 폴더(`.debug-profile*`, `.api-profile*`)를 지우면 로그인도 지워진다. 처음부터 다시 하고 싶을 때만 지운다.
